## 2. 重点疑点逐项结论（评审取证）

- **a. updateIdentity wire 契约**：四场景（口令⇄密钥、留空保留、密钥校验失败）全部正确——4 字段字面 map 显式回传，显式 null 经 encodeCell 清列；留空保留回传 pull 解密后的原口令明文；服务端校验只 reqStr(label,username) 不会拒绝；base_rev 冲突显式报错非静默覆盖。
- **b. identities 实体特征**：rowToWire 全列回填（null 也在键），username+key_id 组合唯一于 identity（对照 7 类实体列清单逐一排除）；deleteIdentity 守卫与 deleteKey/deleteHost 对称。
- **c. PinchRecognizer 生命周期**：p2 接管可靠；p1 中途接管不成立（BUG-2 已修）；无指针泄漏；cancel 接线完整（长按中捏合不残留菜单 timer）。
- **d. ArrowGestureTracker 数学**：cap 3*spacing 相对当前档位正确；换向 `_accum=0` 是防误发键的正确选择；10 用例锁定行为。
- **e. 粘贴菜单 timer**：UI 线程串行无竞态；菜单弹出/取消/被捏合抢占三路径都清 tracker。
- **f. xterm 叉子**：回调 null 时原语句逐字节未动 → 桌面零回归；_isDoubleTap 状态机自洽；LongPressCancel 新接线 no-op 安全。
- **g. Kotlin 前台服务**：start/stop 排队序安全、channel 幂等、API 26/29/34 兼容面正确（BUG-1/4/6 修复后）；注记：dataSync 类型在 Android 15+ 有系统时限，非代码缺陷。
- **h. TerminalPrefs**：load 幂等有守卫；kvPut 时机修正（BUG-3）；静态单例对现有纯函数测试无污染。
- **i. 对话框 busy**：防重复提交正确；FAB/桌面按钮显隐正确；barrier 问题已修（BUG-7）。
